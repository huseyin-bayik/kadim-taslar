# Kadim Taşlar

Tarayıcıda çalışan, 3D low-poly, tek oyunculu bir RPG. Kurtları avla, Kadim Taşları kır, demircide kılıcını yükselt.

**Oyna:** https://huseyin-bayik.github.io/kadim-taslar/

Telefona kurmak için: linki aç → Android'de Chrome menüsü → "Ana ekrana ekle" / iPhone'da Safari → Paylaş → "Ana Ekrana Ekle".
